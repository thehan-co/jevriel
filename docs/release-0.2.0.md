# JEVRIEL 0.2.0 release evidence

The release adds user-selected Light/Deep adoption, portable skill/runtime installation, a JSON CLI, secret-manager references, explicit provider setup, reported-cost receipts and runnable examples. Private operation and reusable distribution are kept separate.

## Verification

- Node suite: 49 passing tests, including provider adapters, secret-command failure handling, reported/unknown/zero cost, invalid-answer charges, CLI input, installation, adoption transitions and fresh stdio MCP behavior.
- Python benchmark suite: 7 passing tests.
- A fresh MCP process reports version 0.2.0 and nine tools. A disabled session refuses inference with zero provider attempts.
- npm dry-run inventory: 68 files, with no private research, provider configuration, adoption settings, credentials, local receipts or Python caches.
- Codex plugin and skill validators pass; Claude marketplace validation passes.
- Portable skill reference links resolve. Public changes contain no private machine paths or secret references.

## Bounded live probe

On 2026-09-28, OpenRouter setup completed one synthetic Choice request. A separate synthetic daily-triage request returned valid Choice, Noul and Score answers from `typesafe/jev-1.13-20260917`. That mixed request reported 507.72 ms at the wrapper and USD 0.000022806 in provider usage. Secret-manager startup and all host overhead are not included in that wrapper timing. The private outer receipt retains whole-path timing.

The pure example policy kept the reported record conflict in review at all three demonstration queue thresholds. This validates transport, response handling and that policy branch. Two live requests are not an accuracy benchmark or evidence of savings. No baseline LLM or private corpus was evaluated for this release. Other provider routes have contract fixtures; their account-specific live access remains to be verified by their users.

## Adoption boundary

Deep is opt-in host-instruction guidance. It asks the agent to evaluate workflows for useful JEV judgments. It does not intercept all programs, schedule background work, bypass permissions, or certify every host's prompt compliance. Light is the default; the current-process disabled switch remains effective. Fresh-session behavioral qualification on each target AI host is still required before treating prompt compliance as proven.

## Provenance and publication

Public sources are linked from the skill's source map. No source-text dump or private research is distributed. Tests use original synthetic examples. The upstream judgment/session modules remain pinned and unchanged. The public release is transferred as a reviewed code/docs commit; the author's private worktree branch and local settings are not pushed.

# Public release policy

Effective 19 October 2026, the public JEVRIEL code and skill release is frozen at version 0.2.0. The source baseline before this documentation notice is `00acdbed6c308c02d8c4351f5a2bd83b63d489f9`. The existing release tag and installable source remain available.

Future marketplace editions are developed privately. Visit [Han Rabinovitz on Agensi](https://www.agensi.io/creators/han-hanoch-rabinovitz) for current availability. A submission awaiting review is not a live product; the storefront is the place to check.

The first marketplace edition polishes the existing four JEVRIEL workflows: new projects, existing apps, daily agent work and Flight Tests. It provides packaged access through Agensi with revised onboarding and supporting guidance. It does not claim exclusive access to the original open-source method or runtime. Read the marketplace listing for the exact contents, requirements and price.

The public code and documentation retain Apache-2.0, with existing upstream notices and the separately stated artwork terms. Previously granted open-source rights remain intact. Paid editorial additions are identified in their own package; a marketplace purchase does not narrow the independent Apache grants.

This public edition receives no promised future feature updates or support SLA. API providers, host tools and model availability are external dependencies. Keep secrets outside the repository and inspect dependencies before using the frozen runtime. The repository is retained as an archived public reference once this notice is published.
